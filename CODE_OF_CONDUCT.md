# Code of Conduct

## Expectation

Be precise, be kind, review the code not the person. DNS is critical infrastructure; review rigor is care, not hostility.

## Unacceptable

Harassment, discrimination, intimidation, dismissive review, sleeping on security reports.

## Enforcement

Report via private security channel (`SECURITY.md`) or maintainer email `daedaevibin@ik.me`. Maintainer investigates, may warn, temporarily or permanently ban from contribution, and will not retaliate against reporters.

## Scope

Applies in repo, issues, PRs, and when representing Heimdallr elsewhere.
