# Branding

## Name

**Heimdallr** — Old Norse. The god who watches the bridge.

- Use: `Heimdallr` (capital H, lower r terminal).
- Binary: `heimdallr` (lower).
- Service: `heimdallr.service`.
- Repo: `github.com/Veridian-Zenith/Heimdallr`.

## Mark

- Sigil: `H` formed from `Hagall` rune + bridge arch, stroke Amber (#f59e0b) on Void Black (#0a0a0a).
- Rosemary for display, Iosevka for code blocks.

## Usage rules

- Do not use Veridian Zenith or Heimdallr marks to endorse a fork without written permission.
- Derivative web consoles must replace the loading screen sigil with own marks.
- OSL-3.0 requires retaining LICENSE notices — keep copyright adjacent to license.
