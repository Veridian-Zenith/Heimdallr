## What this means (short, not a substitute for LICENSE)

- **Use freely**, including commercially.
- **Distribution or network use = distribution:** External Deployment (LICENSE:28) means if others can use it over a network, you must offer source under OSL-3.0.
- **Derivative works stay OSL-3.0.**
- **Keep attribution:** Retain copyright notices and carry a prominent notice that you modified it.
- **No trademark grant:** Cannot use Veridian Zenith/Heimdallr marks to endorse derived products without permission.

## Why OSL-3.0 (not GPL-3.0)

Technitium is GPL-3.0. GPL-3.0 network use is not conveying, so a hosted fork could hide changes. OSL-3.0 External Deployment closes that — it forces network operators to share source.

## Compliance checklist

1. Include verbatim LICENSE with every copy.
2. Host source repo or offer written source for duration of distribution.
3. For external deployment, publish Heimdallr source including changes.
4. Retain copyright header in modified files + add "Modified by ... on ..." notice.
