## Why `OSL-3.0` (not `GPL-3.0` like `Technitium/DnsServer/LICENSE`)

`TechnitiumLibrary` + `DnsServer` are `GPL-3.0`. `GPL-3.0` network use is not conveying, so a hosted fork could hide changes. `OSL-3.0` `External Deployment` (`LICENSE:28-29`) closes that — it is `AGPL`-like copyleft that forces network operators to share. This is the `competition` lever (`Verdandi/README.md:47` same 47-word `Short version`).

## Compliance checklist for distributors

1. Include verbatim `LICENSE` with every copy (`LICENSE:44` `3`).
2. Host source repo or offer written source for duration of distribution (`1(c)` + `23`).
3. For external deployment (`:53`/`:5380` over net), publish Heimdallr source including changes.
4. Retain `Copyright (c) 2026 Veridian Zenith` header in modified files + add `Modified by … on 2026-…` notice (`6`).
5. Do not claim `Open Software License` for a `Modified License` with different terms (`LICENSE:45-46` `16`).
